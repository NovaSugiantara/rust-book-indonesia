Bab ini menyiapkan perkakas yang akan kamu pakai sepanjang situs. Ada tiga hal yang kita kerjakan: memasang Rust lewat `rustup`, menulis dan menjalankan program pertama dengan `rustc`, lalu membuat proyek dengan Cargo. Di akhir bab, kamu mulai proyek Kasir Warung yang akan kita lanjutkan di bab-bab berikutnya.

Tidak semua orang perlu memasang Rust hari ini. Kalau kamu hanya ingin mencoba, halaman-halaman di bab ini punya playground yang berjalan di browser. Instalasi baru wajib saat kamu ingin memakai `cargo` di komputer sendiri.

## Yang kamu butuhkan

- Terminal. Di macOS dan Linux namanya Terminal, di Windows bisa Command Prompt atau PowerShell.
- Editor teks. VS Code, Zed, Neovim, atau editor apa pun yang nyaman.
- Koneksi internet untuk mengunduh Rust dan menjalankan playground.

Tidak perlu akun, server, atau layanan berbayar. Situs ini statis dan semua contoh berjalan di komputer atau playground publik.

## Urutan belajar

1. [Instalasi](instalasi/) menjelaskan `rustup`, linker, dan cara memastikan Rust sudah terpasang.
2. [Hello, World!](hello-world/) membahas program pertama, fungsi `main`, dan makro `println!`.
3. [Hello, Cargo!](hello-cargo/) memperkenalkan Cargo, `Cargo.toml`, dan perintah build.
4. [Studi kasus: Kasir Warung](studi-kasus/) memakai semua bekal itu untuk membuat proyek nyata.

Baca berurutan kalau ini pertama kalinya kamu memakai Rust. Kalau kamu sudah pernah memakai `rustc` dan `cargo`, langsung ke studi kasus tidak masalah.

:::note[Kenapa begini?]
Bab ini memakai dua alat yang terlihat mirip. `rustc` adalah compiler: ia mengubah satu file `.rs` menjadi program. Cargo adalah alat yang mengatur proyek: ia memanggil `rustc` untukmu, menyimpan konfigurasi, dan mengunduh dependency. Untuk program kecil, `rustc` cukup. Begitu proyek punya banyak file, Cargo jauh lebih rapi.
:::

:::tip[Tips]
Saat membaca contoh terminal, tanda `$` hanya penanda awal perintah. Jangan ikut mengetiknya. Baris yang tidak diawali `$` adalah output dari perintah sebelumnya.
:::
