## Untuk siapa situs ini

Situs ini dibuat untuk fullstack atau backend web developer yang ingin memahami Rust dengan urutan yang jelas. Kamu sudah menulis kode di JavaScript/TypeScript, PHP, Go, atau Python, dan sudah terbiasa dengan HTTP, database, serta REST.

Kamu tidak perlu sudah menguasai Rust. Kamu perlu nyaman memakai terminal, Git, package manager, dan membaca pesan error. Materi ini tidak menjelaskan dasar pemrograman dari nol. Fokusnya adalah cara Rust bekerja dan bagaimana memakai Rust untuk layanan backend.

Yang akan kamu latih:

- ownership, borrow, dan cara Rust mengatur memory tanpa garbage collector;
- struct, enum, trait, generic, dan lifetime untuk memodelkan data serta abstraksi;
- error handling sebagai nilai, bukan exception;
- test, iterator, smart pointer, thread, dan async;
- satu studi kasus yang tumbuh dari CLI sampai server, lalu capstone API.

## Dari mana materinya

Situs ini adaptasi dari [The Rust Programming Language](https://doc.rust-lang.org/stable/book/) oleh Steve Klabnik, Carol Nichols, dan Chris Krycho, dengan kontribusi dari komunitas Rust. Buku aslinya dilisensikan MIT atau Apache-2.0.

Urutan bab, contoh kode, dan fakta teknis mengikuti buku asli. Yang berubah adalah bahasa dan cara penyampaiannya. Kalau ada penjelasan di sini yang terasa berbeda dari buku asli atau dokumentasi resmi Rust, percayai sumber aslinya.

:::tip[Belum mau memasang Rust?]
Contoh Rust di Bab 1 bisa dijalankan di playground selama ada koneksi internet. Instalasi baru dibutuhkan saat kamu ingin menjalankan `cargo` dan membuat proyek di komputer sendiri.
:::
