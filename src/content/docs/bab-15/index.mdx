Reference biasa meminjam data dan mengikuti aturan borrow checker. Smart pointer adalah tipe yang berperilaku seperti pointer tetapi membawa kemampuan tambahan, seperti memiliki data di heap, menghitung jumlah pemilik, atau menegakkan aturan borrow saat runtime.

Di backend, smart pointer muncul saat menyimpan data besar di heap, membuat struktur pohon, berbagi cache read-only dalam satu thread, atau mencatat state yang perlu diubah lewat reference immutable.

## Urutan bab

1. [Box](box/) membahas data di heap dan tipe rekursif.
2. [Deref](deref/) membahas dereference, `Deref`, dan deref coercion.
3. [Drop](drop/) membahas cleanup otomatis dan `std::mem::drop`.
4. [Rc](rc/) membahas kepemilikan bersama dengan reference counting.
5. [Interior mutability](interior-mutability/) membahas `RefCell` dan `Rc<RefCell<T>>`.
6. [Reference cycle](reference-cycles/) membahas kebocoran memory dan `Weak`.
7. [Studi kasus: cache menu](studi-kasus/) memakai `Rc<RefCell<MenuCache>>` dan batasnya.

:::note[Kenapa begini?]
Smart pointer tetap mengikuti aturan ownership. Yang berubah adalah cara data dimiliki atau diakses. `Box` memindahkan data ke heap, `Rc` memungkinkan beberapa pemilik, dan `RefCell` memindahkan pemeriksaan borrow ke runtime. Tidak ada yang menghapus kebutuhan memahami ownership.
:::

:::tip[Tips]
Gunakan smart pointer hanya saat kebutuhan ownership biasa tidak cukup. `Box` untuk indirection, `Rc` untuk berbagi dalam satu thread, dan `RefCell` saat mutasi lewat reference immutable benar-benar diperlukan.
:::
