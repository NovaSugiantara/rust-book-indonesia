Sampai Bab 7, Kasir Warung memakai array berukuran tetap. Itu cukup untuk tiga item contoh, tetapi tidak untuk daftar pesanan yang jumlahnya berubah. Bab ini membahas tiga collection yang paling sering dipakai: `Vec<T>`, `String`, dan `HashMap<K, V>`.

Di backend, ketiganya muncul terus: daftar item response, nama dan teks, cache berdasarkan kunci, rekap transaksi, dan hasil query yang dikelompokkan. Kunci memakai collection dengan benar adalah memahami kapan data dimiliki, dipinjam, atau dipindahkan.

## Urutan bab

1. [Vector](vectors/) membahas daftar dinamis, indexing, `get`, iterasi, dan enum untuk tipe berbeda.
2. [String](strings/) membahas UTF-8, `String` vs `&str`, penggabungan, dan mengapa string tidak bisa diindeks dengan angka.
3. [HashMap](hash-maps/) membahas key-value, ownership, entry API, dan rekap kata.
4. [Studi kasus: Kasir Warung](studi-kasus/) mengganti array dengan `Vec` dan menu dengan `HashMap`.

:::caution[Hati-hati]
Collection memiliki data di heap. Operasi seperti `push` bisa mengubah alokasi, sehingga reference ke elemen tidak boleh hidup bersamaan dengan perubahan struktur. Borrow checker akan menolak kombinasi yang berbahaya.
:::

:::tip[Tips]
Pilih collection dari bentuk datanya. Butuh urutan berdasarkan indeks, pakai `Vec`. Butuh teks, pakai `String` atau `&str`. Butuh pencarian berdasarkan kunci, pakai `HashMap`.
:::
