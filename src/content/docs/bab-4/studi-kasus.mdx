Setelah Bab 3, Kasir Warung punya perhitungan total tetapi masih menerima array secara utuh. Di bab ini kita menambahkan nama pelanggan sebagai `String`, lalu mengubah fungsi perhitungan agar meminjam data dengan `&str` dan slice.

## Dari array ke pinjaman

Bab 3 memakai fungsi `hitung_subtotal(harga: u32, jumlah: u32)`. Di sini kita memakai slice agar satu fungsi bisa menjumlahkan beberapa item sekaligus tanpa memiliki array-nya.

## Kode lokal lengkap

Versi lokal tetap membaca jumlah barang dari terminal. Bagian input sama dengan Bab 3, lalu data dipinjam ke fungsi header dan subtotal.

```rust
use std::io;

fn cetak_header(nama: &str, jumlah_barang: usize) {
    println!("========================================");
    println!("           KASIR WARUNG BU SRI");
    println!("        Jl. Melati No. 12, Bandung");
    println!("Pelanggan: {nama}");
    println!("Jumlah barang: {jumlah_barang}");
    println!("========================================");
}

fn hitung_subtotal(harga: &[u32], jumlah: &[u32]) -> u32 {
    let mut subtotal = 0;

    for i in 0..harga.len() {
        subtotal += harga[i] * jumlah[i];
    }

    subtotal
}

fn hitung_diskon(subtotal: u32) -> u32 {
    if subtotal >= 40_000 {
        subtotal * 10 / 100
    } else {
        0
    }
}

fn main() {
    let nama_pelanggan = String::from("Bu Sri");
    let mut jumlah_barang: usize = 0;

    loop {
        println!("Jumlah barang (1-3):");

        let mut input = String::new();

        io::stdin()
            .read_line(&mut input)
            .expect("Gagal membaca input");

        let jumlah: usize = match input.trim().parse() {
            Ok(angka) => angka,
            Err(_) => {
                println!("Masukkan angka, bukan teks. Coba lagi.");
                continue;
            }
        };

        match jumlah {
            1..=3 => {
                jumlah_barang = jumlah;
                break;
            }
            _ => println!("Jumlah harus 1 sampai 3. Coba lagi."),
        }
    }

    cetak_header(&nama_pelanggan, jumlah_barang);

    let daftar_harga = [12_000, 8_000, 15_000];
    let daftar_jumlah = [1, 2, 1];

    let subtotal = hitung_subtotal(
        &daftar_harga[..jumlah_barang],
        &daftar_jumlah[..jumlah_barang],
    );
    let diskon = hitung_diskon(subtotal);
    let total = subtotal - diskon;

    println!("Subtotal: Rp{subtotal}");
    println!("Diskon:   Rp{diskon}");
    println!("Total:    Rp{total}");
    println!("Terima kasih, {nama_pelanggan}.");
}
```

## Keadaan setelah Bab 4

- Nama pelanggan disimpan sebagai `String` dan dipinjam ke fungsi header sebagai `&str`.
- Subtotal menerima slice `&[u32]`, bukan array atau `Vec`.
- Array harga tetap dimiliki `main` dan tidak di-clone.
- Belum ada struct. Data item masih berupa array terpisah.
- `jumlah_barang` tetap dibatasi 1 sampai 3 karena array berukuran tetap.

:::note[Kenapa begini?]
Fungsi yang hanya membaca sebaiknya meminjam, bukan mengambil ownership. Dengan `&str` dan `&[u32]`, pemanggil tetap memiliki data dan bisa memakainya lagi. Clone baru diperlukan kalau ada dua pemilik yang benar-benar independen.
:::
