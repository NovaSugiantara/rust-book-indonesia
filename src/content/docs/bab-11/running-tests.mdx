`cargo test` menjalankan semua test yang ditemukan. Kamu bisa memfilter, mengatur thread, menampilkan output, dan melewati test yang mahal.

## Menjalankan semua test

```console
$ cargo test
running 3 tests
test tests::add_three_and_two ... ok
test tests::add_two_and_two ... ok
test tests::one_hundred ... ok
test result: ok. 3 passed; 0 failed; 0 ignored; 0 measured
```

Test dijalankan secara paralel menggunakan thread. Kalau test saling mengganggu karena state global, jalankan satu per satu:

```console
$ cargo test -- --test-threads=1
```

## Filter nama test

Argumen setelah `--` diteruskan ke test runner, bukan ke program. Filter nama test dengan substring:

```console
$ cargo test one_hundred
running 1 test
test tests::one_hundred ... ok
test result: ok. 1 passed; 0 failed; 0 ignored; 2 filtered out
```

Filter `add` menjalankan semua test yang namanya mengandung `add`.

## Menampilkan output

Secara default, output `println!` dari test yang lulus ditangkap. Untuk melihatnya:

```console
$ cargo test -- --show-output
```

Output dari test yang gagal biasanya tetap ditampilkan untuk membantu diagnosis.

## Test yang diabaikan

Test yang mahal bisa ditandai `#[ignore]`.

```rust
#[test]
#[ignore]
fn expensive_test() {
    // test yang membutuhkan waktu lama
}
```

`cargo test` akan menandainya `ignored`. Jalankan hanya test yang diabaikan dengan:

```console
$ cargo test -- --ignored
```

## Contoh kode yang diuji

<RustPlayground
  code={`fn add_two(a: u64) -> u64 {
    a + 2
}

fn main() {

    assert_eq!(add_two(3), 5);
    assert_eq!(add_two(100), 102);
    println!("Semua kasus lulus");
}`}
  filename="src/main.rs"

Di proyek nyata, kasus-kasus ini menjadi fungsi `#[test]` terpisah. Playground tidak menjalankan test runner, jadi `main` dipakai untuk memperlihatkan nilainya.

:::note[Kalau di bahasa lain]
Jest bisa menjalankan test dengan filter nama, Go memakai `go test -run`, PHPUnit memakai `--filter`, dan pytest memakai `-k`. Rust memakai argumen setelah `--` untuk meneruskan opsi ke test runner.
:::

:::tip[Tips]
Jalankan test yang paling relevan saat iterasi cepat, lalu jalankan seluruh suite sebelum commit. Filter membantu, tetapi jangan lupa test yang tidak ikut filter.
:::
