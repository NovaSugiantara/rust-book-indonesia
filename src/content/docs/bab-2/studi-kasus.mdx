Di Bab 1 kita berhenti dengan proyek `kasir_warung` yang mencetak header struk. Sekarang kita tambahkan satu kemampuan baru: kasir dapat memasukkan jumlah barang, dan program hanya menerima angka yang masuk akal. Validasi ini memakai `loop` dan `match`, dua hal yang baru saja kamu pelajari.

## Batas jumlah barang

Untuk sementara, batasi jumlah barang antara 1 dan 3. Batas ini terasa sempit untuk warung sungguhan, tetapi ada alasan teknis: Bab 3 akan memakai array berukuran tetap untuk daftar harga contoh. Array belum bisa bertambah panjang. Bab 8 akan memperkenalkan `Vec` yang bisa menampung jumlah barang bebas.

Batasan ini juga membuat latihan validasi lebih jelas. Kita punya dua jenis input salah:

- teks yang bukan angka, misalnya `dua`;
- angka di luar rentang, misalnya `0` atau `10`.

Keduanya harus ditolak tanpa membuat program berhenti.

## Kode lokal

Buka proyek `kasir_warung` dari Bab 1, lalu ganti isi `src/main.rs` dengan kode berikut. Kode ini butuh input dari terminal, jadi jalankan dengan `cargo run`, bukan di playground.

```rust
use std::io;

fn main() {
    println!("========================================");
    println!("           KASIR WARUNG BU SRI");
    println!("        Jl. Melati No. 12, Bandung");
    println!("========================================");

    let mut jumlah_barang = 0;

    loop {
        println!("Jumlah barang (1-3):");

        let mut input = String::new();

        io::stdin()
            .read_line(&mut input)
            .expect("Gagal membaca input");

        let jumlah: u32 = match input.trim().parse() {
            Ok(angka) => angka,
            Err(_) => {
                println!("Masukkan angka, bukan teks. Coba lagi.");
                continue;
            }
        };

        match jumlah {
            1..=3 => {
                jumlah_barang = jumlah;
                break;
            }
            _ => println!("Jumlah harus 1 sampai 3. Coba lagi."),
        }
    }

    println!();
    println!("Jumlah barang: {jumlah_barang}");
    println!("========================================");
}
```

Contoh percakapan di terminal:

```text
========================================
           KASIR WARUNG BU SRI
        Jl. Melati No. 12, Bandung
========================================
Jumlah barang (1-3):
dua
Masukkan angka, bukan teks. Coba lagi.
Jumlah barang (1-3):
10
Jumlah harus 1 sampai 3. Coba lagi.
Jumlah barang (1-3):
2

Jumlah barang: 2
========================================
```

Program menolak `dua` karena `parse` gagal. Program menolak `10` karena angkanya di luar rentang. Setelah `2`, program keluar dari loop dan mencetak jumlah barang.

## Apa yang berubah dari Bab 1

Bab 1 hanya mencetak header. Sekarang program punya satu input dan satu aturan validasi. Header tetap sama, jadi struk masih bisa dikenali.

Yang belum ada: harga, jumlah per item, subtotal, diskon, dan total. Semua itu ditambahkan di Bab 3. Jangan menambahkan perhitungan sekarang. Fokus dulu pada memastikan input tidak bisa merusak program.

:::note[Kenapa begini?]
Validasi di batas input mencegah data buruk masuk ke bagian lain program. Kalau jumlah barang sudah dijamin 1 sampai 3, kode perhitungan di Bab 3 tidak perlu menebak-nebak apakah nilainya nol, negatif, atau sangat besar.
:::

:::tip[Tips]
Coba masukkan spasi sebelum angka, misalnya `  2`. `trim` membuang spasi itu, jadi program tetap menerima input. Coba juga menekan Enter tanpa mengetik apa pun. `parse` akan gagal dan program meminta input lagi.
:::
