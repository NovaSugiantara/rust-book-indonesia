Kita mulai dari proyek kosong. Masuk ke folder tempat kamu menyimpan proyek, lalu buat proyek baru bernama `guessing_game`.

```console
$ cargo new guessing_game
$ cd guessing_game
```

Cargo membuat folder proyek, `Cargo.toml`, folder `src` dengan `main.rs`, dan `.gitignore`. Isi `Cargo.toml` kurang lebih seperti ini:

```toml
[package]
name = "guessing_game"
version = "0.1.0"
edition = "2024"

[dependencies]
```

Bagian `[dependencies]` masih kosong karena proyek ini belum memakai crate eksternal. Kita akan menambah satu dependency di halaman angka rahasia.

## Program bawaan Cargo

Buka `src/main.rs`. Cargo sudah mengisi file itu dengan program `Hello, world!`:

<RustPlayground
  code={`fn main() {
    println!("Hello, world!");
}`}
  filename="src/main.rs"
/>

Jalankan proyek dari folder `guessing_game`:

```console
$ cargo run
   Compiling guessing_game v0.1.0 (file:///projects/guessing_game)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.45s
     Running `target/debug/guessing_game`
Hello, world!
```

Perintah `cargo run` mengompilasi kode lalu menjalankan hasilnya. Selama mengembangkan game, kamu akan memakai perintah ini berkali-kali. Cargo hanya mengompilasi ulang bagian yang berubah, jadi putaran berikutnya biasanya lebih cepat.

:::tip[Tips]
Kalau kamu hanya ingin memeriksa error tanpa menjalankan program, pakai `cargo check`. Saat sedang mengubah banyak baris, `cargo check` lebih cepat daripada `cargo run`.
:::

## Satu file untuk sementara

Semua kode game di bab ini ditulis di `src/main.rs`. Untuk proyek kecil, satu file sudah cukup. Bab 7 akan membahas cara memecah proyek menjadi beberapa module ketika ukurannya bertambah.

Ganti isi `src/main.rs` sedikit demi sedikit mengikuti halaman berikutnya. Jangan menyalin seluruh kode final sekaligus. Kamu akan kehilangan kesempatan melihat bagaimana setiap bagian bekerja.
