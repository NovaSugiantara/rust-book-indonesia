Sekarang kita punya tebakan dari pemain dan angka rahasia. Langkah berikutnya adalah membandingkan keduanya. Di sinilah `match` mulai bekerja.

## String bukan angka

Tebakan dibaca sebagai `String`, sedangkan angka rahasia adalah angka. Rust tidak mengizinkan perbandingan langsung antara keduanya. Kode berikut sengaja salah:

}`}

Compiler akan melaporkan tipe yang tidak cocok. `cmp` membutuhkan dua nilai dengan tipe yang sama, dan `String` tidak sama dengan `i32`. Kita harus mengubah tebakan menjadi angka lebih dulu.

## Mengubah String menjadi angka

Tambahkan baris ini setelah `read_line`:

```rust
let guess: u32 = guess.trim().parse().expect("Please type a number!");
```

Ada tiga hal yang terjadi di baris itu.

Pertama, `trim()` membuang spasi dan baris baru di awal dan akhir string. Saat pengguna mengetik `50` lalu menekan Enter, string berisi `50\n`. `trim()` mengubahnya menjadi `50`.

Kedua, `parse()` mengubah string menjadi tipe angka. Karena `parse` bisa gagal, ia mengembalikan `Result`. Kita memberi tipe `u32` supaya Rust tahu angka jenis apa yang diinginkan. Tanpa anotasi tipe, compiler tidak bisa menebak apakah kamu ingin `u32`, `i32`, atau tipe angka lain.

Ketiga, kita membuat variabel baru bernama `guess`. Nama itu sama dengan variabel `String` sebelumnya. Rust mengizinkan ini lewat shadowing. Variabel baru menutupi variabel lama, dan tipe keduanya boleh berbeda. Setelah baris ini, `guess` adalah angka, bukan string.

:::note[Kenapa begini?]
Shadowing berguna saat kamu mengubah nilai dari satu tipe ke tipe lain tanpa perlu nama seperti `guess_string` dan `guess_number`. Variabel lama tetap ada sampai scope-nya selesai, tetapi nama `guess` sekarang merujuk ke variabel baru.
:::

Kalau input bukan angka, `parse` mengembalikan `Err`, dan `.expect("Please type a number!")` akan menghentikan program. Di halaman loop, kita akan mengganti `expect` dengan `match` supaya program bisa meminta input lagi tanpa crash.

## Ordering dan match

Tambahkan import berikut di bagian atas file:

```rust
use std::cmp::Ordering;
```

Lalu bandingkan kedua angka:

```rust
match guess.cmp(&secret_number) {
    Ordering::Less => println!("Too small!"),
    Ordering::Greater => println!("Too big!"),
    Ordering::Equal => println!("You win!"),
}
```

`cmp` membandingkan dua nilai dan mengembalikan `Ordering`. `Ordering` punya tiga varian: `Less`, `Greater`, dan `Equal`. Nama-nama itu cukup jelas: tebakan lebih kecil, lebih besar, atau sama dengan angka rahasia.

`match` memeriksa nilai dari `cmp` dan menjalankan arm pertama yang cocok. Setiap arm terdiri dari pattern dan kode yang dijalankan. Di contoh ini, ketiga kemungkinan `Ordering` ditangani. `match` harus lengkap. Kalau ada varian yang belum ditangani, compiler akan memberi error.

:::note[Kalau di bahasa lain]
`match` terasa seperti `switch` atau `case`, tetapi compiler memaksa semua kemungkinan ditangani. `Result` juga bukan exception. Error dikembalikan sebagai nilai, bukan dilempar ke atas. Di JS, PHP, atau Python kamu mungkin memakai `try/catch`; di Rust, kegagalan yang bisa dipulihkan biasanya masuk ke `Result` dan diolah dengan `match` atau operator `?` di bab berikutnya.
:::

`secret_number` tidak diberi anotasi tipe secara eksplisit di kode game. Karena dibandingkan dengan `guess: u32` lewat `cmp`, Rust menyimpulkan bahwa `secret_number` juga `u32`. Ini contoh type inference yang bekerja saat informasinya cukup.

## Kode lokal sampai tahap ini

Di komputer sendiri, `src/main.rs` sekarang berisi kode seperti ini. Bagian input masih memakai `read_line`, jadi jalankan dengan `cargo run`.

```rust
use std::cmp::Ordering;
use std::io;

use rand::prelude::*;

fn main() {
    println!("Guess the number!");

    let secret_number = rand::rng().random_range(1..=100);

    println!("The secret number is: {secret_number}");

    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    let guess: u32 = guess.trim().parse().expect("Please type a number!");

    println!("You guessed: {guess}");

    match guess.cmp(&secret_number) {
        Ordering::Less => println!("Too small!"),
        Ordering::Greater => println!("Too big!"),
        Ordering::Equal => println!("You win!"),
    }
}
```

Program ini masih hanya menerima satu tebakan. Setelah satu tebakan, program selesai. Halaman berikutnya menambahkan loop supaya pemain bisa mencoba lagi.
