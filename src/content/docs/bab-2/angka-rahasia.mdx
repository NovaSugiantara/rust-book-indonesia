Game akan membosankan kalau angka rahasianya sama setiap kali dijalankan. Kita butuh angka acak. Rust belum menyertakan pembangkit angka acak untuk kebutuhan umum di standard library, jadi kita memakai crate `rand`.

Crate adalah paket kode Rust. Proyek yang sedang kita bangun adalah binary crate, yaitu program yang bisa dijalankan. `rand` adalah library crate, yaitu kumpulan kode yang dipakai oleh program lain dan tidak dijalankan sendirian.

## Menambahkan rand ke Cargo.toml

Buka `Cargo.toml` dan tambahkan `rand` di bawah `[dependencies]`:

```toml
[package]
name = "guessing_game"
version = "0.1.0"
edition = "2024"

[dependencies]
rand = "0.10.1"
```

Angka `0.10.1` adalah versi minimum yang kita minta. Cargo memahami Semantic Versioning, jadi `0.10.1` adalah singkatan dari `^0.10.1`: versi 0.10.1 atau lebih baru, tetapi masih di bawah 0.11.0. Selama API publiknya tidak berubah, Cargo boleh memakai patch release yang lebih baru.

Simpan file, lalu jalankan `cargo build`:

```console
$ cargo build
    Updating crates.io index
  Downloaded rand v0.10.1
  ...
   Compiling rand v0.10.1
   Compiling guessing_game v0.1.0 (file:///projects/guessing_game)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 2.03s
```

Cargo mengunduh `rand` beserta crate yang dibutuhkan `rand`, lalu mengompilasi semuanya. Baris dan versi patch bisa berbeda di komputermu. Selama masih di seri 0.10, kode di bab ini seharusnya cocok.

## Cargo.lock

Build pertama dengan dependency membuat `Cargo.lock`. File itu mencatat versi persis setiap crate yang dipakai. Build berikutnya akan memakai versi yang sama sampai kamu memintanya berubah. Ini membuat build bisa direproduksi di komputer lain.

Kalau kamu ingin memperbarui dependency dalam batas versi di `Cargo.toml`, jalankan:

```console
$ cargo update
```

Jangan mengedit `Cargo.lock` manual. Cargo yang mengelola isinya.

## Membuat angka acak

Tambahkan import dan dua baris berikut ke `src/main.rs`:

```rust
use rand::prelude::*;

fn main() {
    let secret_number = rand::rng().random_range(1..=100);

    println!("The secret number is: {secret_number}");
}
```

`use rand::prelude::*;` membawa item yang paling sering dipakai dari crate `rand` ke scope. Tanda `*` berarti semua item publik di module `prelude`.

`rand::rng()` mengembalikan random number generator untuk thread saat ini. Generator itu di-seed oleh sistem operasi, jadi hasilnya berbeda antar program.

Method `.random_range(1..=100)` meminta angka dalam rentang 1 sampai 100. Tanda `..=` membuat batas atas ikut disertakan, berbeda dengan `..` yang berhenti sebelum batas atas.

Baris `println!` mencetak angka rahasia. Itu berguna saat pengembangan, tetapi harus dihapus di versi final. Kalau angka rahasia dicetak, pemain tidak perlu menebak lagi.

:::tip[Tips]
Kalau ingin membaca dokumentasi crate yang sudah diunduh, jalankan `cargo doc --open`. Dokumentasi itu dibuat dari crate di proyekmu, jadi versinya cocok dengan yang sedang dipakai.
:::

:::note[Kenapa begini?]
Rentang `1..=100` lebih mudah dibaca daripada menulis `rand::rng().random_range(1..101)`. Keduanya menghasilkan angka 1 sampai 100, tetapi yang pertama menyatakan batas akhir secara eksplisit.
:::
