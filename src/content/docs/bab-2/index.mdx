Bab ini langsung dipakai untuk membangun program. Kita akan membuat game tebak angka: program memilih angka acak antara 1 dan 100, kamu mengetik tebakan, lalu program memberi tahu apakah tebakanmu terlalu kecil, terlalu besar, atau tepat. Permainan berhenti saat tebakan benar.

Di sepanjang bab, kamu akan bertemu `let`, `match`, method, associated function, crate eksternal, dan loop. Belum semua detailnya dibahas sekarang. Bab 3 sampai Bab 6 akan kembali ke konsep-konsep itu dengan lebih dalam. Untuk sekarang, fokusnya adalah membuat program yang berjalan.

## Yang akan kamu bangun

- Proyek Cargo baru bernama `guessing_game`.
- Input dari terminal dengan `std::io`.
- Angka rahasia acak dari crate `rand`.
- Perbandingan tebakan dengan `std::cmp::Ordering`.
- Loop yang terus meminta tebakan sampai pemain menang atau memasukkan input yang tidak valid.

## Urutan bab

1. [Menyiapkan proyek](persiapan/) membuat proyek dan menjalankan program bawaan Cargo.
2. [Membaca input](input/) memakai `read_line`, `String`, dan `Result`.
3. [Angka rahasia](angka-rahasia/) menambahkan crate `rand`.
4. [Membandingkan tebakan](membandingkan/) memakai `Ordering` dan `match`.
5. [Loop dan input valid](loop/) menutup permainan dan menangani input salah.
6. [Studi kasus: Kasir Warung](studi-kasus/) memakai loop dan `match` untuk memvalidasi jumlah barang.

:::caution[Playground tidak bisa membaca input]
Contoh di situs ini bisa dijalankan di playground, tetapi playground tidak punya terminal interaktif. Kode yang memanggil `read_line` akan langsung mendapat akhir input. Karena itu, setiap contoh yang butuh input tampil dalam dua bentuk: versi playground dengan nilai yang sudah di-hardcode, dan versi lengkap untuk dijalankan dengan `cargo run` di komputer sendiri.
:::

:::tip[Tips]
Jalankan program setiap kali satu bagian selesai. Game ini tumbuh sedikit demi sedikit. Kesalahan yang muncul setelah perubahan kecil lebih mudah dilacak daripada kesalahan setelah semua kode ditulis sekaligus.
:::
