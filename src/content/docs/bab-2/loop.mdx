Sampai sekarang program hanya menerima satu tebakan. Itu belum terasa seperti game. Kita butuh loop supaya pemain bisa menebak berkali-kali.

## Memindahkan input ke dalam loop

Kata kunci `loop` membuat blok di dalamnya dijalankan terus-menerus. Pindahkan bagian yang meminta input, membaca, mengubah ke angka, dan membandingkan ke dalam `loop`.

```rust
loop {
    println!("Please input your guess.");

    let mut guess = String::new();

    io::stdin()
        .read_line(&mut guess)
        .expect("Failed to read line");

    let guess: u32 = guess.trim().parse().expect("Please type a number!");

    println!("You guessed: {guess}");

    match guess.cmp(&secret_number) {
        Ordering::Less => println!("Too small!"),
        Ordering::Greater => println!("Too big!"),
        Ordering::Equal => {
            println!("You win!");
            break;
        }
    }
}
```

Setelah pemain menang, `break` keluar dari loop. Karena loop adalah bagian terakhir `main`, program juga selesai.

Kalau kamu menjalankan versi ini, pemain tidak bisa keluar dengan tebakan biasa sampai menebak angka yang benar. Menekan Ctrl+C menghentikan program dari terminal. Cara itu bekerja, tetapi bukan cara yang nyaman untuk keluar dari game.

## Menangani input yang bukan angka

Sebelumnya kita memakai `.expect` pada `parse`. Kalau pemain mengetik `quit` atau `abc`, program langsung panic. Kita bisa mengganti `expect` dengan `match` supaya input yang salah diabaikan dan pemain diminta menebak lagi.

```rust
let guess: u32 = match guess.trim().parse() {
    Ok(num) => num,
    Err(_) => continue,
};
```

`parse` mengembalikan `Result`. Kalau berhasil, arm `Ok(num)` mengambil angka dari dalam `Ok` dan menjadikannya nilai baru untuk `guess`. Kalau gagal, arm `Err(_)` cocok dengan error apa pun. Tanda `_` adalah catch-all yang berarti kita tidak peduli isi error-nya. Kode di arm itu adalah `continue`, yang melewati sisa iterasi dan kembali ke awal loop.

Dengan perubahan ini, input non-angka tidak menghentikan program. Pemain cukup mengetik tebakan lain.

:::caution[Hati-hati]
Jangan menaruh `continue` di luar loop. Compiler akan menolak karena tidak ada loop yang bisa dilanjutkan. Keyword `break` dan `continue` hanya berlaku di dalam loop.
:::

## Kode final versi lokal

Versi final menghapus `println!` yang mencetak angka rahasia. Kode lengkapnya seperti ini:

```rust
use std::cmp::Ordering;
use std::io;

use rand::prelude::*;

fn main() {
    println!("Guess the number!");

    let secret_number = rand::rng().random_range(1..=100);

    loop {
        println!("Please input your guess.");

        let mut guess = String::new();

        io::stdin()
            .read_line(&mut guess)
            .expect("Failed to read line");

        let guess: u32 = match guess.trim().parse() {
            Ok(num) => num,
            Err(_) => continue,
        };

        println!("You guessed: {guess}");

        match guess.cmp(&secret_number) {
            Ordering::Less => println!("Too small!"),
            Ordering::Greater => println!("Too big!"),
            Ordering::Equal => {
                println!("You win!");
                break;
            }
        }
    }
}
```

Jalankan dengan `cargo run`, lalu coba beberapa tebakan. Coba juga mengetik teks yang bukan angka. Program harus tetap meminta input tanpa panic.

Simpan versi yang sudah berjalan sebelum mencoba eksperimen. Kalau eksperimen gagal, kamu bisa kembali ke versi yang stabil tanpa menulis ulang semuanya.
:::
