`cargo install` memasang binary crate secara lokal. Perintah ini bukan pengganti package manager sistem. Tujuannya memudahkan developer Rust memasang alat CLI yang dibagikan di crates.io.

## Hanya binary target

Yang bisa dipasang adalah package dengan binary target, yaitu program yang dihasilkan dari `src/main.rs` atau file binary lain. Library tanpa binary tidak bisa dijalankan sendiri dan tidak bisa dipasang dengan cara ini.

Contoh alat terkenal adalah `ripgrep`, implementasi pencarian file yang disebut di Bab 12:

```console
$ cargo install ripgrep
    Updating crates.io index
  Downloaded ripgrep v14.1.1
  Downloaded 1 crate (213.6 KB) in 0.40s
  Installing ripgrep v14.1.1
--snip--
   Compiling grep v0.3.2
    Finished `release` profile [optimized] target(s) in 6.73s
  Installing ~/.cargo/bin/rg
   Installed package `ripgrep v14.1.1` (executable `rg`)
```

Nama package `ripgrep` menghasilkan binary `rg`. Baris `Installing ~/.cargo/bin/rg` menunjukkan lokasi hasil pemasangan.

## Folder bin dan PATH

Binary dipasang ke folder `bin` pada installation root. Kalau Rust dipasang lewat rustup tanpa konfigurasi khusus, lokasinya `$HOME/.cargo/bin`.

Folder itu harus ada di `PATH` agar perintah seperti `rg` bisa dipanggil dari direktori mana pun. Kalau `cargo install` berhasil tetapi perintah tidak ditemukan, periksa `PATH` sebelum menganggap pemasangan gagal.

## Binary target sederhana

    let nama = std::env::args()

    println!("Pakai: kasir-laporan <file>");

Program ini punya `main`, sehingga bisa menjadi binary target. Kalau kode yang sama diletakkan di `src/lib.rs` tanpa binary, `cargo install` tidak punya program untuk dipasang.

## Setelah dipasang

Binary yang dipasang berjalan seperti program lain. Ia tidak membutuhkan Cargo saat dijalankan, karena sudah dikompilasi menjadi executable.

Memperbarui versi berarti menjalankan `cargo install` lagi untuk package yang sama. Cargo memasang versi yang tersedia di registry sesuai permintaan.

:::note[Kalau di bahasa lain]
Di Node.js, `npm install -g` memasang package global dan binary-nya masuk ke folder bin npm. Di PHP, `composer global require` memasang package global. Di Go, `go install package@version` memasang binary ke `GOBIN` atau `$GOPATH/bin`. Rust memakai `cargo install` dan folder `~/.cargo/bin` sebagai lokasi umum.
:::

:::tip[Tips]
Untuk alat internal, pertimbangkan memasang dari path lokal selama pengembangan. Untuk alat publik, dokumentasikan nama binary dan cara menambahkan folder bin ke `PATH`.
:::
