Cargo bisa diperluas tanpa mengubah Cargo itu sendiri. Kalau ada binary bernama `cargo-sesuatu` di `PATH`, perintah `cargo sesuatu` akan menjalankannya.

## Cara kerja

Aturannya sederhana:

- Nama binary diawali `cargo-`.
- Binary berada di `PATH`.
- Cargo meneruskan sisa argumen ke binary tersebut.
- Subcommand muncul di `cargo --list`.

Contoh, binary `cargo-laporan` bisa dipanggil sebagai:

```console
$ cargo laporan --file transaksi.csv
```

Cargo mencari `cargo-laporan`, menjalankannya, dan meneruskan `--file transaksi.csv`.

## Memasang extension

Extension bisa dibagikan sebagai crate binary dan dipasang dengan `cargo install`. Setelah binary masuk folder `bin` yang ada di `PATH`, subcommand langsung bisa dipakai seperti perintah Cargo bawaan.

<RustPlayground
  code={`fn main() {
    let args: Vec<String> = std::env::args().collect();
    let nama = args.first().map(String::as_str).unwrap_or("cargo-laporan");

    println!("Menjalankan {nama}");
    println!("Argumen: {:?}", &args[1..]);
    println!("Subcommand ini akan dipanggil oleh cargo sebagai: cargo laporan");
}`}
  filename="src/main.rs"
  label="Binary yang bisa menjadi custom command"
/>

Program ini menerima argumen seperti binary biasa. Yang membuatnya menjadi subcommand Cargo adalah nama file dan lokasinya di `PATH`, bukan kode di dalamnya.

## Kapan membuat custom command

Custom command berguna untuk alur kerja yang berulang, misalnya:

- memeriksa struktur workspace,
- membuat laporan dari data proyek,
- menjalankan pemeriksaan khusus tim.

Untuk kebutuhan yang hanya dipakai sekali, shell script atau alias lebih sederhana. Custom command masuk akal saat alat perlu dibagikan, punya logika cukup kompleks, atau ingin dipasang lewat Cargo.

## Batasannya

Cargo tidak memvalidasi isi custom command. Kalau binary gagal, error dan exit code berasal dari program itu. Dokumentasikan perilaku, argumen, dan status keluarnya agar bisa dipakai di CI.

:::note[Kalau di bahasa lain]
npm menyediakan `npm exec` dan binary dari package lokal atau global. Composer punya perintah global dan script composer. Go tidak punya mekanisme subcommand `go` dari binary eksternal dengan pola nama seperti Cargo; alat biasanya dipanggil langsung. Rust memakai konvensi nama `cargo-*` yang sederhana dan memanfaatkan `PATH`.
:::

:::tip[Tips]
Beri nama binary dengan awalan `cargo-` dan uji dari direktori lain untuk memastikan ia benar-benar ditemukan lewat `PATH`, bukan karena kebetulan berada di folder proyek.
:::
