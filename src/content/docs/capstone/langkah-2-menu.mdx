Menu adalah sumber harga. Pesanan tidak boleh menerima harga dari client; harga harus dibaca dari database. Langkah ini membuat CRUD menu dan memastikan kode menu dinormalisasi.


    axum 0.8 memakai path parameter `{kode}`, bukan `:kode`.

  <StudyCaseStep
    title="Query daftar dan detail"
    goal="Mengembalikan menu sebagai JSON dengan tipe yang jelas."
  >
    ```rust
    pub async fn list_menu(pool: &SqlitePool) -> Result<Vec<MenuResponse>, AppError> {
        let rows = sqlx::query_as::<_, (String, String, i64, i64)>(
            "SELECT kode, nama, harga, aktif FROM menu ORDER BY kode",
        )
        .fetch_all(pool)
        .await?;

        Ok(rows
            .into_iter()
            .map(|(kode, nama, harga, aktif)| MenuResponse {
                kode,
                nama,
                harga: harga as u32,
                aktif: aktif != 0,
            })
            .collect())
    }

    pub async fn get_menu(pool: &SqlitePool, kode: &str) -> Result<MenuResponse, AppError> {
        let kode = normalize_kode(kode);
        let row = sqlx::query_as::<_, (String, String, i64, i64)>(
            "SELECT kode, nama, harga, aktif FROM menu WHERE kode = ?",
        )
        .bind(&kode)
        .fetch_optional(pool)
        .await?
        .ok_or_else(|| AppError::NotFound(format!("menu {kode} tidak ditemukan")))?;

        Ok(MenuResponse {
            kode: row.0,
            nama: row.1,
            harga: row.2 as u32,
            aktif: row.3 != 0,
        })
    }
    ```

    `fetch_optional` membedakan data tidak ditemukan dari error database. `ok_or_else` mengubah `None` menjadi `AppError::NotFound`.

    <Fragment slot="hint">
      Jangan memakai `unwrap` pada hasil query yang bergantung pada input pengguna.
    </Fragment>

    <Fragment slot="solution">
      Client menerima 200 dengan JSON atau 404 dengan body error yang konsisten.
    </Fragment>
  </StudyCaseStep>

  <StudyCaseStep
    title="Validasi dan simpan menu"
    goal="Menolak kode, nama, atau harga yang tidak valid."
  >
    ```rust
    pub async fn create_menu(
        pool: &SqlitePool,
        request: CreateMenuRequest,
    ) -> Result<MenuResponse, AppError> {
        let kode = normalize_kode(&request.kode);
        let nama = request.nama.trim();

        if kode.is_empty() {
            return Err(AppError::BadRequest("kode menu tidak boleh kosong".to_string()));
        }

        if nama.is_empty() {
            return Err(AppError::BadRequest("nama menu tidak boleh kosong".to_string()));
        }

        if request.harga == 0 {
            return Err(AppError::BadRequest("harga menu harus lebih dari nol".to_string()));
        }

        let result = sqlx::query("INSERT INTO menu (kode, nama, harga, aktif) VALUES (?, ?, ?, 1)")
            .bind(&kode)
            .bind(nama)
            .bind(i64::from(request.harga))
            .execute(pool)
            .await;

        match result {
            Ok(_) => get_menu(pool, &kode).await,
            Err(sqlx::Error::Database(error)) if error.is_unique_violation() => Err(
                AppError::Conflict(format!("menu {kode} sudah terdaftar")),
            ),
            Err(error) => Err(error.into()),
        }
    }
    ```

    Kode menu dinormalisasi menjadi huruf besar. `unique_violation` dipetakan ke 409, bukan 500.

    <Fragment slot="hint">
      `normalize_kode` melakukan `trim().to_uppercase()` agar `kopi` dan `KOPI` tidak menjadi dua menu berbeda.
    </Fragment>

    <Fragment slot="solution">
      Input salah menghasilkan 400, duplikat menghasilkan 409, dan data valid menghasilkan 201.
    </Fragment>
  </StudyCaseStep>
</StudyCase>

## Coba dengan curl

```console
$ curl -sS -X POST http://127.0.0.1:3000/api/menu \
  -H 'content-type: application/json' \
  -d '{"kode":"KOPI","nama":"Kopi","harga":12000}'
{"kode":"KOPI","nama":"Kopi","harga":12000,"aktif":true}

$ curl -sS http://127.0.0.1:3000/api/menu
[{"kode":"KOPI","nama":"Kopi","harga":12000,"aktif":true}]
```

:::note[Kalau di bahasa lain]
Express memakai `app.get` dan `app.post`, NestJS memakai controller dan decorator, Gin memakai `c.JSON`, Laravel memakai resource controller, dan FastAPI memakai decorator route. axum memakai `Router` dan handler async dengan extractor bertipe.
:::

:::tip[Tips]
Gunakan kode menu yang stabil dan mudah dibaca mesin, misalnya `KOPI`. Nama tampilan tetap disimpan terpisah di field `nama`.
:::
