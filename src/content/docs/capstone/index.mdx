:::caution[Materi tambahan di luar Rust Book]
Capstone ini bukan bagian dari 21 bab The Rust Programming Language. Kodenya ada di `capstone-kasir/` dan dibangun dari dokumentasi resmi axum, tokio, serta sqlx versi stabil yang dipakai proyek. Materi ini melanjutkan domain Kasir Warung dari Bab 1 sampai 21.
:::

Capstone mengubah Kasir Warung dari CLI dan server TCP manual menjadi REST API dengan database. Fokusnya bukan lagi membangun listener HTTP, tetapi merancang endpoint, state bersama, error response, transaksi database, test, dan operasi release.

## Endpoint

| Method | Path | Fungsi |
| --- | --- | --- |
| `GET` | `/health` | Status layanan |
| `GET` | `/api/menu` | Daftar menu |
| `POST` | `/api/menu` | Tambah menu |
| `GET` | `/api/menu/{kode}` | Detail menu |
| `PUT` | `/api/menu/{kode}` | Ubah menu |
| `DELETE` | `/api/menu/{kode}` | Hapus menu |
| `POST` | `/api/orders` | Buat pesanan dengan validasi |
| `GET` | `/api/orders/{id}` | Detail pesanan |
| `POST` | `/api/orders/{id}/pay` | Bayar lewat trait object |
| `PATCH` | `/api/orders/{id}/status` | Ubah status dengan aturan transisi |

| `GET` | `/api/events` | Event latar belakang |

:::note[Kenapa axum?]
axum memakai ekosistem Tokio, hyper, dan tower yang sudah muncul di Bab 17 dan 21. Routing serta extractor-nya eksplisit, sehingga alur request mudah dibaca setelah membangun server TCP manual.
:::

:::tip[Tips]
Jalankan server hanya di `127.0.0.1` saat latihan. Sebelum deploy, tambahkan autentikasi, pembatasan request, timeout, dan backup database.
:::
