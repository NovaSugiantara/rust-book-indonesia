Proyek Bonus berdiri sendiri dan bukan bagian dari 21 bab The Rust Book. Kode lengkapnya ada di folder `proyek-bonus/` di repositori. Halaman ini dan halaman langkah memakai potongan kode yang sama dengan folder tersebut.

Proyek ini adalah URL shortener dengan statistik klik. Ukurannya cukup kecil untuk diselesaikan dalam satu sesi, tetapi memakai konsep dari seluruh Rust Book: ownership, trait object, error handling, iterator, smart pointer, thread, async, sampai handler HTTP.

Bedanya dengan Capstone Kasir Warung: Capstone tumbuh bertahap sepanjang 21 bab dan berfokus pada domain kasir. Proyek Bonus adalah contoh jadi yang berdiri sendiri, supaya kamu bisa melihat semua konsep bekerja bersama dalam satu program.

## Yang dibangun

- API HTTP dengan axum 0.8 dan Tokio.
- Short link dengan kode acak atau kode kustom.
- Redirect 307 ke URL tujuan.
- Statistik klik per link dan rekap semua link.
- Trait `Store` dengan implementasi in-memory dan SQLite.
- Worker async untuk menyimpan klik dan worker thread untuk audit.
- Test unit, integration test endpoint, dan doc test.
- Build release dan graceful shutdown.

## Endpoint

| Method | Path | Fungsi |
| --- | --- | --- |
| `GET` | `/health` | Cek layanan |
| `POST` | `/api/links` | Membuat short link |
| `GET` | `/api/links` | Daftar link |
| `GET` | `/api/stats` | Rekap semua link |
| `GET` | `/api/stats/{code}` | Statistik satu link |
| `GET` | `/api/audit` | Klik terakhir dari worker audit |
| `GET` | `/{code}` | Redirect ke target |

## Menjalankan

Jalankan server dari folder `proyek-bonus`:

```console
$ cargo run
```

Default memakai SQLite dan membuat `shortener.db`. Untuk mode tanpa database:

```console
$ STORE=memory cargo run
```

Buat link, lalu lihat redirect dan statistik:

```console
$ curl -i -X POST http://127.0.0.1:3000/api/links \
  -H 'Content-Type: application/json' \
  -d '{"target":"https://example.com/promo","custom_code":"promo"}'

$ curl -i http://127.0.0.1:3000/promo
$ curl http://127.0.0.1:3000/api/stats/promo
```

## Arsitektur singkat

```text
HTTP handler (axum)
   ├── membaca / menulis Link lewat Arc<dyn Store>
   ├── mengirim kode ke channel klik -> worker async -> SQLite
   └── mengirim kode ke channel audit -> std thread -> buffer Mutex
```

`AppState` menyimpan trait object store, dua channel, dan buffer audit. Semua handler menerima state itu lewat extractor `State`.

:::note[Kalau di bahasa lain]
Di Express, state biasanya berupa module singleton atau object yang di-inject. Di Gin, state sering berupa struct yang dibawa ke handler. Di Laravel, service container menyediakan dependency. Di Rust, kita membuat `Arc<AppState>` secara eksplisit dan memberikannya ke router. Bentuknya lebih manual, tetapi compiler memeriksa thread safety dan kepemilikan state.
:::
