    Kode pendek tidak boleh diperlakukan sebagai `String` biasa. Kita membuat newtype `ShortCode` supaya validasi hanya terjadi di satu tempat. Kode yang sudah lolos validasi tidak bisa tertukar dengan target URL atau nama pengguna.

    ```rust
    pub struct ShortCode(String);

    impl ShortCode {
        pub fn parse(input: &str) -> Result<Self, AppError> {
            let value = input.trim();

            if !(MIN_LENGTH..=MAX_LENGTH).contains(&value.len()) {
                return Err(crate::bad_request!(
                    "kode harus {MIN_LENGTH} sampai {MAX_LENGTH} karakter"
                ));
            }

            if !value
                .chars()
                .all(|character| character.is_ascii_alphanumeric())
            {
                return Err(crate::bad_request!(
                    "kode hanya boleh berisi huruf dan angka"
                ));
            }

            Ok(Self(value.to_string()))
        }

        pub fn generate() -> Self {
            let mut rng = rand::rng();
            let code = (0..GENERATED_LENGTH)
                .map(|_| {
                    let index = rng.random_range(0..ALPHABET.len());
                    ALPHABET[index] as char
                })
                .collect();

            Self(code)
        }

        pub fn as_str(&self) -> &str {
            &self.0
        }
    }
    ```

    `Deref<Target = str>` membuat `ShortCode` bisa dipakai sebagai `&str` saat membaca, tanpa membuka jalan untuk mengubah isinya dari luar module.

    Status link adalah enum, bukan boolean, karena nanti bisa bertambah nilai seperti `Expired` tanpa mengubah tipe field.

    ```rust
    pub enum LinkStatus {
        Active,
        Disabled,
    }

    impl LinkStatus {
        pub fn can_redirect(self) -> bool {
            matches!(self, Self::Active)
        }

        pub fn as_str(self) -> &'static str {
            match self {
                Self::Active => "active",
                Self::Disabled => "disabled",
            }
        }

        pub fn from_db(value: &str) -> Result<Self, AppError> {
            match value {
                "active" => Ok(Self::Active),
                "disabled" => Ok(Self::Disabled),
                other => Err(AppError::Internal(format!("status tidak dikenal: {other}"))),
            }
        }
    }

    pub struct Link {
        pub code: ShortCode,
        pub target: String,
        pub clicks: u64,
        pub status: LinkStatus,
    }

    impl Link {
        pub fn new(code: ShortCode, target: String) -> Self {
            Self {
                code,
                target,
                clicks: 0,
                status: LinkStatus::Active,
            }
        }

        pub fn can_redirect(&self) -> bool {
            self.status.can_redirect()
        }

        pub fn with_status(mut self, status: LinkStatus) -> Self {
            self.status = status;
            self
        }
    }
    ```

      Mulai dari pertanyaan: data apa yang tidak boleh salah tipe? Kode pendek, target URL, jumlah klik, dan status. Setiap jawaban menjadi tipe atau field.
    </Fragment>

## Error sebagai response

`AppError` adalah enum yang mewakili kegagalan yang mungkin terjadi. Setiap varian dipetakan ke status HTTP, lalu `IntoResponse` mengubahnya menjadi JSON.

```rust
pub enum AppError {
    BadRequest(String),
    NotFound,
    Conflict(String),
    Gone,
    Internal(String),
    Database(sqlx::Error),
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        let status = self.status();
        let body = ErrorBody {
            error: self.message(),
        };
        (status, Json(body)).into_response()
    }
}
```

Error database tidak membocorkan detail ke client. Pesan aslinya ditulis ke stderr, sedangkan response hanya berisi pesan umum. Ini penting untuk layanan yang menghadap publik.

:::note[Kalau di bahasa lain]
Di Express, error biasanya dilempar dan ditangkap middleware. Di Laravel, exception dipetakan ke response oleh handler global. Di Rust, error adalah nilai yang dikembalikan lewat `Result`. Implementasi `IntoResponse` berperan seperti error middleware, tetapi dipilih compiler saat tipe error dikembalikan dari handler.
:::
