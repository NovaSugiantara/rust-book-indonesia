Enum mendefinisikan tipe yang nilainya hanya boleh salah satu dari beberapa variant. Setiap variant bisa membawa data sendiri.

## Enum sederhana

Contoh klasik adalah jenis alamat IP. Sebuah alamat hanya bisa IPv4 atau IPv6, tidak keduanya.

<RustPlayground
  code={`#[derive(Debug)]
enum IpAddrKind {
    V4,
    V6,
}

fn route(ip_kind: IpAddrKind) {
    println!("Routing untuk {ip_kind:?}");
}

fn main() {
    let four = IpAddrKind::V4;
    let six = IpAddrKind::V6;

    route(four);
    route(six);
}`}
  filename="src/main.rs"
  label="Enum sederhana dengan dua variant"
/>

Variant diakses lewat nama enum: `IpAddrKind::V4`. `V4` dan `V6` adalah nilai dengan tipe yang sama, yaitu `IpAddrKind`.

## Variant yang membawa data

Variant bisa membawa data. Ini menghindari struct tambahan yang menyimpan enum dan nilai secara terpisah.

<RustPlayground
  code={`#[derive(Debug)]
enum IpAddr {
    V4(String),
    V6(String),
}

fn main() {
    let home = IpAddr::V4(String::from("127.0.0.1"));
    let loopback = IpAddr::V6(String::from("::1"));

    println!("{home:?}");
    println!("{loopback:?}");
}`}
  filename="src/main.rs"
  label="Variant enum dengan data String"
/>

Setiap variant bisa memiliki tipe dan jumlah data yang berbeda.

<RustPlayground
  code={`#[derive(Debug)]
enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
}

fn main() {
    let home = IpAddr::V4(127, 0, 0, 1);
    let loopback = IpAddr::V6(String::from("::1"));

    println!("{home:?}");
    println!("{loopback:?}");
}`}
  filename="src/main.rs"
  label="Variant dengan jumlah data berbeda"
/>

Nama variant juga berfungsi sebagai constructor. `IpAddr::V4(...)` memanggil fungsi yang menghasilkan nilai enum.

Contoh lain, `Message`, menunjukkan variant tanpa data, variant dengan field bernama, dan variant dengan tuple:

<RustPlayground
  code={`#[derive(Debug)]
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}

fn main() {
    let pesan = Message::Write(String::from("halo"));
    println!("{pesan:?}");
}`}
  filename="src/main.rs"
  label="Enum dengan berbagai bentuk data"
/>

Enum juga bisa punya method lewat `impl`, sama seperti struct.

<RustPlayground
  code={`#[derive(Debug)]
enum Message {
    Quit,
    Write(String),
}

impl Message {
    fn call(&self) {
        println!("Pesan diproses: {self:?}");
    }
}

fn main() {
    let pesan = Message::Write(String::from("halo"));
    pesan.call();
}`}
  filename="src/main.rs"
  label="Method pada enum"
/>

## Option

Rust tidak memiliki null. Sebagai gantinya, standard library menyediakan `Option<T>`:

```rust
enum Option<T> {
    None,
    Some(T),
}
```

`Option` dan kedua variant-nya sudah ada di prelude, jadi bisa dipakai tanpa `Option::`:

<RustPlayground
  code={`fn main() {
    let some_number = Some(5);
    let some_char = Some('e');
    let absent_number: Option<i32> = None;

    println!("{some_number:?} {some_char:?} {absent_number:?}");
}`}
  filename="src/main.rs"
  label="Nilai Some dan None"
/>

Tipe `Some(5)` adalah `Option<i32>`, sedangkan `Some('e')` adalah `Option<char>`. `None` membutuhkan anotasi tipe karena compiler tidak bisa menebak tipe isi yang tidak ada.

`Option<T>` bukan `T`. Kamu tidak bisa langsung memakai `Option<i8>` dalam operasi `i8`:

<RustPlayground
  code={`fn main() {
    let x: i8 = 5;
    let y: Option<i8> = Some(5);

    let sum = x + y;
}`}
  expectError
  filename="src/main.rs"
  label="Contoh error menambahkan Option ke angka"
/>

Compiler melaporkan bahwa `Add<Option<i8>>` tidak diimplementasikan untuk `i8`. Pesan ini memaksa kamu mengambil nilai dari `Option` dan menangani `None` terlebih dahulu.

:::note[Kalau di bahasa lain]
Di TypeScript, pilihan seperti ini sering dimodelkan dengan discriminated union dan `null` atau `undefined`. Di Go, enum biasanya berupa konstanta bertipe dan `nil` untuk pointer atau interface. Di PHP, enum punya variant dan bisa memiliki nilai backed. Rust menyatukan pilihan dan data di enum, lalu memakai `Option` untuk kemungkinan tidak ada nilai. Tidak ada `null` implisit.
:::

:::caution[Hati-hati]
Jangan memakai `unwrap()` pada `Option` hanya untuk mendapatkan nilai. Kalau `None`, program panic. Gunakan `match`, `if let`, atau method yang punya perilaku jelas untuk nilai kosong.
:::
