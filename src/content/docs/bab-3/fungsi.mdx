Fungsi adalah blok kode yang punya nama dan bisa dipanggil. Kamu sudah memakai satu fungsi penting sejak Bab 1: `main`, titik masuk program. Sekarang kita membuat fungsi sendiri.

Rust memakai snake case untuk nama fungsi dan variabel: huruf kecil semua, dengan garis bawah antar kata. Contohnya `hitung_total`, bukan `HitungTotal`.

## Mendefinisikan dan memanggil fungsi

Fungsi dideklarasikan dengan `fn`, diikuti nama, tanda kurung, dan body di dalam kurung kurawal.

<RustPlayground
  code={`fn main() {
    println!("Hello, world!");

    another_function();
}

fn another_function() {
    println!("Another function.");
}`}
  filename="src/main.rs"
  label="Mendefinisikan dan memanggil fungsi"
/>

Urutan definisi tidak penting. `another_function` didefinisikan setelah `main`, tetapi tetap bisa dipanggil karena berada di scope yang sama.

## Parameter

Parameter adalah variabel yang menjadi bagian dari signature fungsi. Tipe setiap parameter wajib ditulis.

<RustPlayground
  code={`fn main() {
    another_function(5);
}

fn another_function(x: i32) {
    println!("The value of x is: {x}");
}`}
  filename="src/main.rs"
  label="Fungsi dengan satu parameter"
/>

Kalau ada beberapa parameter, pisahkan dengan koma:

<RustPlayground
  code={`fn main() {
    print_labeled_measurement(5, 'h');
}

fn print_labeled_measurement(value: i32, unit_label: char) {
    println!("The measurement is: {value}{unit_label}");
}`}
  filename="src/main.rs"
  label="Fungsi dengan dua parameter"
/>

Anotasi tipe di signature membuat compiler tahu nilai apa yang boleh dikirim. Compiler juga bisa memberi pesan error yang lebih tepat saat pemanggilan salah tipe.

## Statement dan expression

Function body terdiri dari statement, expression, atau keduanya.

- Statement melakukan sesuatu dan tidak menghasilkan nilai.
- Expression menghasilkan nilai.

`let y = 6;` adalah statement. `5 + 6` adalah expression yang menghasilkan 11. Memanggil fungsi adalah expression. Memanggil makro juga expression.

Blok kurung kurawal juga bisa menjadi expression:

<RustPlayground
  code={`fn main() {
    let y = {
        let x = 3;
        x + 1
    };

    println!("The value of y is: {y}");
}`}
  filename="src/main.rs"
  label="Blok sebagai expression"
/>

Baris `x + 1` tidak diakhiri titik koma. Tanpa titik koma, baris itu menjadi expression yang menghasilkan nilai untuk blok. Kalau ditambah titik koma, nilainya menjadi statement dan blok mengembalikan unit.

Statement tidak bisa dipakai sebagai nilai. Kode berikut sengaja salah:

<RustPlayground
  code={`fn main() {
    let x = (let y = 6);
}`}
  expectError
  filename="src/main.rs"
  label="Contoh error statement dipakai sebagai nilai"
/>

Compiler melaporkan bahwa `let` bukan expression di posisi itu. Di Rust, assignment tidak mengembalikan nilai seperti di beberapa bahasa lain.

## Nilai balik

Fungsi bisa mengembalikan nilai. Tipe nilai balik ditulis setelah `->`. Nilai balik adalah nilai expression terakhir di body fungsi, kecuali kamu memakai `return` lebih awal.

<RustPlayground
  code={`fn five() -> i32 {
    5
}

fn main() {
    let x = five();

    println!("The value of x is: {x}");
}`}
  filename="src/main.rs"
  label="Fungsi yang mengembalikan nilai"
/>

Fungsi `five` hanya berisi angka 5 tanpa titik koma. Angka itu adalah expression terakhir, jadi nilainya dikembalikan.

<RustPlayground
  code={`fn main() {
    let x = plus_one(5);

    println!("The value of x is: {x}");
}

fn plus_one(x: i32) -> i32 {
    x + 1
}`}
  filename="src/main.rs"
  label="Fungsi dengan parameter dan nilai balik"
/>

Kalau `x + 1` diberi titik koma, fungsi tidak lagi mengembalikan `i32`:

<RustPlayground
  code={`fn main() {
    let x = plus_one(5);

    println!("The value of x is: {x}");
}

fn plus_one(x: i32) -> i32 {
    x + 1;
}`}
  expectError
  filename="src/main.rs"
  label="Contoh error titik koma mengubah expression menjadi statement"
/>

Compiler akan menyebut `mismatched types`: fungsi menjanjikan `i32`, tetapi body-nya menghasilkan `()`. Pesan help biasanya menyarankan menghapus titik koma.

:::caution[Hati-hati]
Titik koma mengubah expression menjadi statement. Di akhir fungsi yang mengembalikan nilai, titik koma yang tidak sengaja bisa menjadi sumber error yang membingungkan.
:::

:::note[Kenapa begini?]
Rust berbasis expression. Banyak hal yang di bahasa lain berupa statement, seperti `if` dan blok, di Rust menghasilkan nilai. Aturan ini membuat kode lebih ringkas, tetapi menuntut kamu memperhatikan titik koma.
:::
