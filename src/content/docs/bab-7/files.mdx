Module inline berguna untuk contoh kecil. Proyek nyata memisahkan module ke file agar setiap bagian mudah dicari.

## Dari inline ke file

Kode inline ini bisa dipindahkan tanpa mengubah path:

<RustPlayground
  code={`mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {
            println!("Tamu ditambahkan");
        }
    }
}

use front_of_house::hosting;

fn main() {
    hosting::add_to_waitlist();
}`}
  filename="src/main.rs"
  label="Module inline sebelum dipecah"
/>

Di proyek Cargo, bentuk file yang setara adalah:

```text
src/
├── main.rs
├── front_of_house.rs
└── front_of_house/
    └── hosting.rs
```

`src/main.rs` mendeklarasikan module:

```rust
mod front_of_house;

use front_of_house::hosting;

fn main() {
    hosting::add_to_waitlist();
}
```

`src/front_of_house.rs` mendeklarasikan submodule:

```rust
pub mod hosting;
```

`src/front_of_house/hosting.rs` berisi implementasinya:

```rust
pub fn add_to_waitlist() {
    println!("Tamu ditambahkan");
}
```

Compiler mencari module di beberapa lokasi. Untuk `mod garden;` di crate root, ia mencari `src/garden.rs` atau `src/garden/mod.rs`. Untuk `mod vegetables;` di `src/garden.rs`, ia mencari `src/garden/vegetables.rs` atau `src/garden/vegetables/mod.rs`.

## Jangan mencampur dua lokasi

Untuk satu module, pilih satu lokasi. Jangan membuat `src/garden.rs` dan `src/garden/mod.rs` sekaligus untuk module yang sama. Compiler bisa bingung dan error.

Pola `mod.rs` masih valid, tetapi gaya yang lebih baru adalah `garden.rs` untuk module dan folder `garden/` untuk submodule. Pilih satu gaya dan konsisten.

## Menjalankan

Dari folder proyek:

```console
$ cargo run
Tamu ditambahkan
```

Karena file module ikut dikompilasi, `cargo run` membaca seluruh module tree dari crate root.

:::note[Kalau di bahasa lain]
Di Go, satu folder biasanya satu package. Di JavaScript, folder dan file module mengikuti import path. Di Rust, module tree ditentukan oleh deklarasi `mod`, bukan hanya lokasi file. File tidak ikut dikompilasi kalau tidak dideklarasikan dari crate root atau module induk.
:::

:::caution[Hati-hati]
Menambah file `.rs` saja tidak cukup. Kamu harus mendeklarasikannya dengan `mod` di module induk. Tanpa deklarasi, file itu tidak menjadi bagian crate.
:::
