Module mengelompokkan definisi yang berhubungan dan menentukan batas privasi. Module bisa berisi fungsi, struct, enum, konstanta, trait, dan module lain.

## Module sederhana

Contoh restoran memisahkan front of house dan back of house. Setiap bagian punya tanggung jawab sendiri.

<RustPlayground
  code={`mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {
            println!("Menambah tamu ke daftar tunggu");
        }
    }

    pub mod serving {
        pub fn take_order() {
            println!("Mencatat pesanan");
        }
    }
}

fn main() {
    front_of_house::hosting::add_to_waitlist();
    front_of_house::serving::take_order();
}`}
  filename="src/main.rs"
  label="Module bertingkat dalam satu file"
/>

Module bisa didefinisikan inline dengan kurung kurawal. Nanti kita akan memindahkannya ke file terpisah.

## Module tree

Module membentuk pohon di bawah module `crate`. Untuk contoh restoran, bentuknya seperti ini:

```text
crate
└── front_of_house
    ├── hosting
    │   ├── add_to_waitlist
    │   └── seat_at_table
    └── serving
        ├── take_order
        ├── serve_order
        └── take_payment
```

`hosting` dan `serving` adalah sibling. Keduanya child dari `front_of_house`. Seluruh pohon berada di bawah `crate`.

## Privacy

Secara default, item di dalam module private terhadap module induk. Untuk membuka akses, gunakan `pub`.

Kalau `hosting` private, module lain tidak bisa memanggil isinya meskipun fungsinya public. Kalau `hosting` public tetapi fungsinya private, fungsi tetap tidak bisa dipanggil dari luar. Keduanya harus public.

<RustPlayground
  code={`mod front_of_house {
    pub mod hosting {
        fn add_to_waitlist() {
            println!("Fungsi ini private");
        }
    }
}

fn main() {
    front_of_house::hosting::add_to_waitlist();
}`}
  expectError
  filename="src/main.rs"
  label="Contoh error memanggil fungsi private"
/>

Pesan compiler menyebut `function add_to_waitlist is private`. Perbaikan yang benar bukan sekadar menambahkan `pub` di sembarang tempat. Pikirkan apakah fungsi itu memang bagian dari API module.

:::note[Kalau di bahasa lain]
Module Rust mirip namespace atau package di bahasa lain, tetapi ada perbedaan penting: privasi adalah default, dan path module adalah bagian dari desain API. Di JavaScript, export harus ditulis eksplisit; di Rust, `pub` adalah kebalikannya, yaitu membuka item yang default-nya private.
:::

:::tip[Tips]
Jaga permukaan public tetap kecil. Buka tipe dan fungsi yang memang dibutuhkan pemakai module. Detail implementasi sebaiknya tetap private agar bisa berubah tanpa memecahkan kode lain.
:::
