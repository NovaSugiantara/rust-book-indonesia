Bab ini menggabungkan banyak konsep sebelumnya menjadi server HTTP sederhana: TCP listener, parsing request, response, file HTML, thread pool, channel, `Arc<Mutex<T>>`, dan `Drop`. Server ini bukan pengganti framework produksi, tetapi memperlihatkan lapisan yang biasanya disembunyikan framework.

## Urutan bab

1. [Server single-thread](single-thread/) membahas listener TCP, request HTTP, response, dan routing sederhana.
2. [Thread pool](multithread/) membahas `ThreadPool`, `Worker`, channel, dan antrean pekerjaan.
3. [Graceful shutdown](graceful-shutdown/) membahas `Drop`, penutupan channel, dan `join`.
4. [Studi kasus: server Kasir Warung](studi-kasus/) menguji endpoint health, menu, laporan, dan 404 lewat curl.

:::note[Kenapa begini?]
Server produksi memakai runtime async, parser HTTP, router, dan connection management. Membangun versi manual membuat kamu memahami masalah yang diselesaikan alat tersebut. Setelah bab ini, Capstone memakai axum dan Tokio untuk hal yang sama dengan lebih sedikit kode infrastruktur.
:::

:::tip[Tips]
Jalankan server hanya di `127.0.0.1` saat belajar. Jangan mengekspos server contoh ke internet tanpa pemahaman keamanan, timeout, dan batas resource.
:::
