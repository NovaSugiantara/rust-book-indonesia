## lib.rs

`ThreadPool` sama seperti halaman sebelumnya, dengan `sender` bertipe `Option` agar bisa ditutup saat `Drop`.

```rust
use std::{
    sync::{mpsc, Arc, Mutex},
    thread,
};

type Job = Box<dyn FnOnce() + Send + 'static>;

pub struct ThreadPool {
    workers: Vec<Worker>,
    sender: Option<mpsc::Sender<Job>>,
}

impl ThreadPool {
    /// Membuat pool dengan jumlah worker tertentu.
    ///
    /// # Panics
    ///
    /// Panic jika `size` nol.
    pub fn new(size: usize) -> ThreadPool {
        assert!(size > 0);

        let (sender, receiver) = mpsc::channel();
        let receiver = Arc::new(Mutex::new(receiver));
        let mut workers = Vec::with_capacity(size);

        for id in 0..size {
            workers.push(Worker::new(id, Arc::clone(&receiver)));
        }

        ThreadPool {
            workers,
            sender: Some(sender),
        }
    }

    pub fn execute<F>(&self, f: F)
    where
        F: FnOnce() + Send + 'static,
    {
        let job = Box::new(f);
        self.sender.as_ref().unwrap().send(job).unwrap();
    }
}

impl Drop for ThreadPool {
    fn drop(&mut self) {
        drop(self.sender.take());

        for worker in self.workers.drain(..) {
            println!("Mematikan worker {}", worker.id);
            if let Err(error) = worker.thread.join() {
                println!("Worker panic: {error:?}");
            }
        }
    }
}

struct Worker {
    id: usize,
    thread: thread::JoinHandle<()>,
}

impl Worker {
    fn new(id: usize, receiver: Arc<Mutex<mpsc::Receiver<Job>>>) -> Worker {
        let thread = thread::spawn(move || loop {
            let message = receiver.lock().unwrap().recv();

            match message {
                Ok(job) => {
                    println!("Worker {id} mengambil pekerjaan");
                    job();
                }
                Err(_) => {
                    println!("Worker {id} disconnected");
                    break;
                }
            }
        });

        Worker { id, thread }
    }
}
```

## main.rs

```rust
use kasir_server::ThreadPool;
use std::{
    io::{BufReader, prelude::*},
    net::{TcpListener, TcpStream},
};

fn main() {
    let listener = TcpListener::bind("127.0.0.1:7878").unwrap();
    let pool = ThreadPool::new(4);

    println!("Server berjalan di http://127.0.0.1:7878");

    for stream in listener.incoming().take(4) {
        let stream = stream.unwrap();

        pool.execute(|| {
            handle_connection(stream);
        });
    }

    println!("Menerima 4 koneksi, mematikan server");
}

fn handle_connection(mut stream: TcpStream) {
    let buf_reader = BufReader::new(&stream);
    let request_line = match buf_reader.lines().next() {
        Some(Ok(line)) => line,
        _ => return,
    };

    let (status_line, body) = match &request_line[..] {
        "GET /health HTTP/1.1" => ("HTTP/1.1 200 OK", "OK\n"),
        "GET /menu HTTP/1.1" => (
            "HTTP/1.1 200 OK",
            "KOPI 12000\nROTI 8000\nTEH 5000\n",
        ),
        "GET /laporan HTTP/1.1" => (
            "HTTP/1.1 200 OK",
            "tunai: Rp58000\nQRIS: Rp80000\n",
        ),
        _ => ("HTTP/1.1 404 NOT FOUND", "tidak ditemukan\n"),
    };

    let response = format!(
        "{status_line}\r\nContent-Type: text/plain; charset=utf-8\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        body.len()
    );

    stream.write_all(response.as_bytes()).unwrap();
}
```

`take(4)` hanya untuk demonstrasi. Server nyata tidak membatasi jumlah koneksi dan perlu sinyal shutdown.

## Jembatan ke Capstone

Server manual ini memperlihatkan lapisan yang digantikan Tokio dan axum:

- Tokio menyediakan runtime async dan I/O non-blocking, sehingga satu thread bisa menangani banyak koneksi yang menunggu.
- Hyper dan axum mem-parse HTTP, mengelola header, keep-alive, dan response.
- Axum menyediakan router, extractor `Path`, `Json`, `State`, dan middleware.
- Graceful shutdown ditangani runtime atau framework, bukan loop `take`.
- Connection pool database dan operasi async menggantikan panggilan blocking di handler.
- Thread pool manual tetap berguna untuk pekerjaan CPU-bound lewat mekanisme seperti `spawn_blocking`.

Capstone akan memakai axum, Tokio, SQLite, dan `sqlx` untuk membangun API Kasir Warung. Fokusnya berpindah dari membangun infrastruktur TCP ke desain endpoint, validasi, error HTTP, dan test.

:::note[Kalau di bahasa lain]
Node.js memakai `http` atau framework seperti Express, dengan event loop dan worker untuk CPU-bound. Go memakai `net/http` dan goroutine. Python memakai `http.server` atau ASGI framework. Rust produksi biasanya memakai hyper dan axum di atas Tokio, bukan server TCP manual.
:::

:::tip[Tips]
Bangun versi manual sekali untuk memahami lapisannya, lalu pakai framework untuk produksi. Jangan mengganti framework dengan server manual hanya untuk menghindari dependency.
:::
