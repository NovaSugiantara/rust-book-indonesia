Bab ini membuka fitur yang lebih jarang dipakai: `unsafe`, associated type, default generic parameter, newtype, never type, dynamically sized type, function pointer, dan macro. Sebagian besar kode backend tidak membutuhkannya langsung, tetapi kamu akan bertemu konsep ini saat membaca crate, menulis FFI, atau membuat derive macro.

## Urutan bab

1. [Unsafe Rust](unsafe/) membahas lima kemampuan unsafe, raw pointer, FFI, dan batas penggunaannya.
2. [Trait lanjutan](advanced-traits/) membahas associated type, operator overloading, disambiguasi, supertrait, dan newtype.
3. [Tipe lanjutan](advanced-types/) membahas newtype, type alias, never type, dan `Sized`.
4. [Fungsi dan closure lanjutan](advanced-functions/) membahas function pointer dan closure yang dikembalikan.
5. [Macro](macros/) membahas `macro_rules!` dan procedural macro, termasuk derive seperti serde.
6. [Studi kasus: validasi dan error response](studi-kasus/) memakai macro kecil dan trait lanjutan.

:::note[Kenapa begini?]
Fitur lanjutan bukan tujuan. Mereka alat untuk masalah tertentu. `unsafe` untuk batas yang tidak bisa dibuktikan compiler, trait lanjutan untuk API library, dan macro untuk menghilangkan boilerplate yang benar-benar berulang.
:::

:::tip[Tips]
Jangan memakai fitur bab ini hanya agar kode terlihat canggih. Kode aman dan jelas lebih bernilai daripada abstraksi yang sulit ditinjau. Setiap `unsafe` perlu alasan dan dokumentasi keselamatan.
:::
